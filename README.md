A browser studio that turns a photo and a caption into GTA-style cover art with neon lettering, then exports it as a PNG.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080, pick a photo, a layout and a colour grade, edit the title, then export 1080×1080, 1080×1350 or 1920×1080 — or all three at once.
